## Maia-3

Maia-3 is AGPL-3.0 software and weights from the University of Toronto's CSSLab. Every build
bundles a converted copy of the Maia3-5M checkpoint (ONNX on desktop, LiteRT on Android and iOS), and
the web build downloads the same LiteRT file from Hugging Face. Every build includes an adapted copy
of its board encoding (the files in the table above). Those files stay under the AGPL. The rest of the app stays
under GPL-3.0-or-later. Section 13 of GPLv3, and section 13 of AGPLv3, expressly allow combining a
GPLv3 work with an AGPLv3 work and conveying the result. Each part keeps its own licence.

In practice, a binary that contains Maia carries both licence texts (Settings → Open-source
licences), and the corresponding source of the Maia parts is in this repository: the checkpoint's
pinned revision and hash, and the reproducible conversion script, in
[docs/maia3-model-provenance.md](docs/maia3-model-provenance.md). The AGPL's network clause (its
section 13) applies to a *modified* Maia offered to users over a network. The app runs Maia on the
device, and the cloud coach in `server/` does not use it. Anyone who moves Maia behind a network
service must offer those users its source.

## External services

The app talks to these services when the relevant feature is used:

* The cloud coach server in [`server/`](server/) (Opening Explainer, Position Chat), when a base URL
  is configured at build time.
* Hugging Face, to download on-device language models (desktop with `CHESS_ENABLE_COACH=1`, web
  with `?coach=1`).
* unpkg and jsDelivr, which serve `filament.js`, `@litert-lm/core` and `@litertjs/core` (LiteRT.js,
  for Maia) to the web build.
* The Lichess opening explorer (`explorer.lichess.org`), for the human-move panel in History, when
  the build enables Lichess and the user is signed in.
* Hugging Face ([`ber4444/maia3-5m-litert`](https://huggingface.co/ber4444/maia3-5m-litert)), from which the web build downloads the Maia-3
  model (pinned commit, SHA-256-checked) the first time Maia is used.
* Google's TensorFlow Lite release bucket (`dl.google.com/tflite-release`), from which the build
  fetches the TensorFlowLiteC framework for iOS (SHA-256-checked; see `fetchLiteRtIos`).
